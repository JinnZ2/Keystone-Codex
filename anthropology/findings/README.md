# Findings

Working packages that produced a revision in this repository. Each folder holds
the research that changed an entry, a metric, or an unknown — not a literature
dump.

FRONTIER.md says what the finding does to the codex. The folders below are the
evidence it was read from.

| Package | Encoded as | What it forced |
| --- | --- | --- |
| [derinkuyu/](derinkuyu/) | `data/infrastructure/derinkuyu_tuff_complex.json` | Longevity measured on documented use, not on a founding myth; tourism metrics rejected; functional succession written as `separation_claim`. Opens **U-C-3**. |
| [kanis-name-semantics/](kanis-name-semantics/) | `data/information/kanis_merchant_archives.json` | Archive encoded as an information technology; name-meaning deferred until attestation context exists. Fails the 300-year bar on purpose. Opens **U-C-4**. First tablet-level result: Kt 86/k 41 hapax cluster (`kt86k41.json`) — distribution without gloss. |

Neither package is a keystone. They are the arguments that made two keystones
encodable without laundering popular claims into `era` and `unlocks`.
